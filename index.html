Resumo baseado na documentação do projeto
01

O problema

Organizar a execução de um plano alimentar: acompanhar refeições e, na evolução prevista, conectar compras, estoque e preparo.

02

A construção

Interface com React e TypeScript, API com Java e Spring Boot e persistência em PostgreSQL. Entregas incrementais com decisões documentadas.

03

As evidências

O repositório registra migrações de banco, testes de interface e API e decisões de autenticação. A base atual funciona localmente.

Para avaliação técnica: decisões e próximos passos +

Decisões registradas

Sessão com cookie HttpOnly, proteção CSRF e hash de senha; migrações com Flyway; demonstração pública separada da conta pessoal.

Próximas entregas

Dieta manual e agenda recorrente, seguidas de estoque, compras e preparo. Esses recursos ainda não fazem parte da base entregue.
